# Paper Diagnostics

These files support the June 9 manuscript analysis but are not all canonical
end-to-end benchmark tables.

- `eval_arxiv_20.txt`, `eval_arxiv_50.txt`, and `eval_arxiv_100.txt` contain
  query-family diagnostics by target query size.
- `eval_mag_*.txt` and `arxiv_eval_results.txt` preserve large-graph and
  cross-query diagnostic output.
- `results_arxiv_non_neural_locked_q20.csv` is the corrected non-neural
  baseline evaluated on the exact locked 200-query Arxiv K-hop suite.

Canonical Glasgow CSVs and their manifest remain one directory above.
